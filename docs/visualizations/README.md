Die gezeigte Ankunftsverspätung ist ein archivbasierter Proxy: Gleichheit von
geplanter und geänderter Zeit kann fehlende Updates enthalten. Die Grafiken
beschreiben zehn ausgewählte NRW-Stationen im September 2025; sie belegen weder
aktuelle noch allgemeine Pünktlichkeit.
